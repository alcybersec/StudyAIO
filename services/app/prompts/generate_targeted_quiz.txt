{# Targeted quiz prompt template — v1.0
   Purpose: Generate a few quiz questions on the topics one student is weakest
            in, for one week of one course (weak-spot engine, ADR 0007 Decision 5).
   Used by: generate_quiz(..., focus=GenerationFocus) in every agent backend,
            via app/agents/targeted_prompts.py. generate_quiz.txt is untouched.
   Variables: course_code, week, summary (optional), extraction_text (the lecture
              with `--- Page N [pN] ---` markers), count, topics (weak-topic labels),
              missed_questions (stems the student got wrong), avoid (stems the
              student already has), page_refs (pages of the missed questions).

   v1.0 (2026-10-15, M33-S2-AI-021): new. Rules reused from the v2.x prompts:
   every item cites the page it comes from (GL#34 standard), formulas are plain
   text (LaTeX does not render for the student), and nothing from outside the
   lecture is introduced (v2.5 bridge-phrase ban). Topic labels, missed stems and
   avoid stems are student and lecture data, so they sit inside delimited blocks
   the model is told to treat as data.
   Measured effect: offline fixtures only (hand-written, evals/targeted_cases);
   no live run yet. Refresh with `python -m evals --live --targeted`.
#}

Generate exactly {{ count }} quiz questions that practise the weak topics above, using only the lecture content above.
Mix approximately 60% multiple_choice and 40% short_answer questions.

Rules:
- Every question must be about one of the weak topics; spread them across the topics, most important first
- Use ONLY facts, definitions, formulas and examples that appear in the lecture content above. Do not add outside material, other techniques, or comparisons to topics the lecture does not mention, and do not use bridge phrases such as "unlike", "compared with" or "points toward" to bring in anything that is not on the pages
- source_page_ref (required): the number of the page whose marker precedes the text the question is based on. It must be a page that appears in the lecture content above; never invent a page and never leave it out
- Write every formula, expression and complexity in plain text exactly as the lecture writes it (for example O(n log n), a[i] = b[i] + 1). Do NOT use LaTeX ($...$, \text{}, \frac)
- Questions should test understanding, not just recall
- multiple_choice: exactly 4 options (A-D), only one correct answer; correct_answer is the letter
- short_answer: answer should be 1-3 sentences, options is null
- Explanations: brief (1-2 sentences) explaining WHY the answer is correct, grounded in the cited page
- Do NOT create trivially obvious questions and do NOT repeat a concept across questions
- Vary difficulty: easy, medium and hard

Respond with ONLY a JSON array (no other text):
